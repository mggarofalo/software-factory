# Integrate and deliver

Input: reviewed changes and the objective's acceptance criteria.

Integrate dependencies, inspect the combined diff and run required checks against
the final candidate. Check the real entry point and failure behavior as needed.
Retain exact revision, commands, results and artifact location. Never combine
passing results from different revisions into a claim of a passing final build.

Publish, merge or deploy only within existing authorization and repository rules.
Prepare the reviewable artifact before asking for any missing final permission.
Present the owner with what changed, how to assess it and material limitations.
Keep implementation, verification, release and acceptance states distinct.

Update the authoritative tracker and resume record. Mark acceptance complete only
when its actual criteria are satisfied; otherwise state the next required action.
Output: candidate, evidence and accurate delivery/acceptance status.
