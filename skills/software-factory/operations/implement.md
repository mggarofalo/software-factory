# Implement a capability

Input: ready work item with observable acceptance and ownership.

Establish expected behavior from authority. Add focused behavioral evidence for
new decisions and relevant rejection paths. Implement through existing boundaries;
extend the owning contract when consumers lack needed facts. Exercise the real
entry point early, before polishing or multiplying tests around a wrong interaction.

Run focused checks during iteration and the required checks before delivery.
Use a negative control or mutation for important decisions where proportionate and
supported. Do not add assertion-free tests, silently regenerate baselines, or
replace a failure with a plausible fallback. Classify incidental findings using
the operating guidance.

Output: reviewable candidate, changed behavior, evidence and remaining limitations.
Use the [handoff](../templates/handoff.md). Acceptance remains a separate decision.
