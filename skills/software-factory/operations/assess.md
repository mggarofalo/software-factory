# Assess the current state

Input: objective, relevant code and existing evidence.

Inspect implementation, tests and actual product entry points. Separate absent
behavior, incorrect behavior, inaccessible behavior and missing evidence. Read
relevant contracts before assuming a feature needs new infrastructure. Record
baseline revision and working-tree state without changing user work.

Output: a short gap map tied to acceptance, existing mechanisms to reuse, and the
current constraint. Stop when the next delivery can be selected. Avoid broad
cleanup inventories unrelated to the objective.
