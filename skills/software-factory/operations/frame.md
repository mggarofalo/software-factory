# Frame an outcome

Input: user intent and existing project state.

Translate intent into an observable user capability, acceptance observations,
constraints and exclusions. Read existing issues first. Infer routine choices;
ask only questions whose answers materially change scope or acceptance. Continue
independent work while optional clarification is pending.

Record the result using existing tracker fields or the
[objective template](../templates/objective.md). Identify the first uncertainty
or delivery. Stop framing when implementation can proceed responsibly; do not
write an exhaustive speculative roadmap.

Output: one authoritative objective and next action.
