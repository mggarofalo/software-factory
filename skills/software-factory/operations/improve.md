# Improve the process

Input: one completed delivery or recurring friction with concrete observations.

Compare intended outcome with accepted behavior. Identify where work waited,
assumptions changed, checks were slow, defects escaped or review caused rework.
Do not infer productivity from commit counts or invented timing estimates.

Choose one bounded process change with an expected benefit and a way to observe
it on the next delivery. Keep useful safeguards; remove duplicated ceremony when
evidence supports doing so. Do not turn the retrospective into a new platform.

Output: observation, proposed change and next evaluation point. Return to delivery.
