# Investigator

Answer one question whose uncertainty blocks a named delivery. Read its authority
and inspect the smallest relevant implementation. Use
[investigation](../operations/investigate.md). Work within the provided time or
evidence bound; do not broaden into a general audit.

Return the answer, supporting evidence, uncertainty, recommended next action and
any reproducible experiment. Label assumptions. Do not implement a major redesign
or open a new work stream without the lead's scope decision.
